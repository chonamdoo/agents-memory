# 의미 검색 루프 진행 기록

규칙은 `program.md`(첫 baseline 전에 고정)를 따른다.

## 준비 (2026-10-21)

- 의미 질의를 작성했다. 군은 S1–S6과 S8이다. claim은 기존 루프와 같다.
  - dev: 의미 질의 84개 + 키워드 질의 102개
  - holdout: 의미 질의 58개 + 키워드 질의 80개
- 실문서 holdout에 바꿔 말한 질문 120개를 추가했다.
  - 정책 Rule 120개를 seed로 무작위 추출했다.
  - 별도 subagent가 Rule마다 질문을 하나씩 썼다(Rule의 고유 단어를 피함).
  - 로컬에만 두고 commit하지 않는다.
- 벡터 경로 무결성 게이트 29건(`tests/test_retrieval_integrity_vector.py`)을 추가했다.
  - 모든 claim이 질의와 완전히 같은 벡터를 갖게 만든 상태에서 기존 무결성 사례를 dense와 hybrid로 다시 실행한다.
  - `eligible`을 우회한 대조 순위는 저장소의 두 번째 방어선(`SOURCE_INELIGIBLE`)이 잡는다.
- 하네스를 작성하고 동결했다(71개 파일). 같은 cache schema를 재사용한다.

## 시도

| # | 비교군 | 결과 | 메모 |
|---|---|---|---|
| X-v0tools | agent 확장(최소 안내), 도구 사용 가능한 subagent가 생성 | 판정 제외 | 의미 hit 41/36/31 → 83/83/82. 다만 subagent가 저장소에 접근할 수 있어 corpus를 읽지 않았음을 증명할 수 없다. 오염 가능성 때문에 판정에서 제외한다. |
| X-v1tools | agent 확장(v1 안내), 같은 조건 | 판정 제외 | 같은 이유. 키워드 MRR 하락으로 discard 판정이 기록됐다. |

- 확장어는 도구를 전혀 쓰지 않는 subagent(질의만 프롬프트로 제공)로 다시 생성한다. 그 결과만 판정에 쓴다.
- dense 비교군은 아직 측정하지 못했다. 모델 CDN(`us.aws.cdn.hf.co`, `cas-server.xethub.hf.co`)이 네트워크 정책으로 막혀 있다.
