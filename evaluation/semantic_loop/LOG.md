# 의미 검색 루프 진행 기록

규칙은 `program.md`(첫 baseline 전에 고정)를 따른다.

## 준비 (2026-10-21)

- 의미 질의를 작성했다. 군은 S1–S6과 S8이다. claim은 기존 루프와 같다.
  - dev: 의미 질의 84개 + 키워드 질의 102개
  - holdout: 의미 질의 58개 + 키워드 질의 80개
- 실문서 holdout에 바꿔 말한 질문 120개를 추가했다.
  - 정책 Rule 120개를 seed로 무작위 추출했다.
  - 별도 subagent가 Rule마다 질문을 하나씩 썼다(Rule의 고유 단어를 피함).
  - 로컬에만 두고 commit하지 않는다.
- 벡터 경로 무결성 게이트 29건(`tests/test_retrieval_integrity_vector.py`)을 추가했다.
  - 모든 claim이 질의와 완전히 같은 벡터를 갖게 만든 상태에서 기존 무결성 사례를 dense와 hybrid로 다시 실행한다.
  - `eligible`을 우회한 대조 순위는 저장소의 두 번째 방어선(`SOURCE_INELIGIBLE`)이 잡는다.
- 하네스를 작성하고 동결했다(71개 파일). 같은 cache schema를 재사용한다.

## 시도

| # | 비교군 | 결과 | 메모 |
|---|---|---|---|
| X-v0tools | agent 확장(최소 안내), 도구 사용 가능한 subagent가 생성 | 판정 제외 | 의미 hit 41/36/31 → 83/83/82. 다만 subagent가 저장소에 접근할 수 있어 corpus를 읽지 않았음을 증명할 수 없다. 오염 가능성 때문에 판정에서 제외한다. |
| X-v1tools | agent 확장(v1 안내), 같은 조건 | 판정 제외 | 같은 이유. 키워드 MRR 하락으로 discard 판정이 기록됐다. |
| X-v0 | agent 확장(최소 안내), 도구 없는 subagent, 정답이 겹치지 않는 묶음으로 생성 | discard | 의미 hit 41/36/31 → 63/62/60(+77), 키워드 hit 97/95/93 → 103/102/102. 그러나 키워드 MRR이 5배 0.608→0.581, 20배 0.600→0.564로 0.02 넘게 떨어졌다. 무결성 44건 통과. |
| X-v2 | 안내 v2(적고 구체적인 확장, 식별자 질의는 0–2개, 넓은 단어 금지), 같은 생성 방식 | discard | 의미 hit 41/36/31 → 82/80/81, 키워드 hit 103/102/101. 키워드 MRR 1배 0.618→0.643, 5배 0.608→0.593은 기준 안이지만 20배 0.600→0.576으로 0.02를 넘었다. 하락은 식별자 질의에 붙은 번역 확장에서 나왔다(예: `refund_queue idempotency` + "환불 큐 멱등성", 1위→13위). 확장 단어가 질의 단어와 같은 무게로 세어지기 때문이다. |
| X-v3 | 안내 v3(식별자 질의는 확장 없음, 오타면 바로잡은 식별자 하나만), 같은 생성 방식 | discard | 의미 hit 83/82/82, 키워드 hit 103/102/100. 식별자 질의 하락은 사라졌다. 그러나 20배 키워드 MRR 0.600→0.571. 이번 하락은 이미 구체적인 자연어 키워드 질의에서 나왔다(1위→2–3위가 9건, "변경 공지를 보내기 전에 누구 검토를 받나" 1→11위). 생성 agent가 3번 묶음에서 `dev-G1-13`(식별자 질의)을 빠뜨려, 안내대로 빈 목록으로 채웠다. |
