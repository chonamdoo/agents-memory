# memory_context query_expansions 안내 (v1)

`memory_context`는 단어 일치로 후보를 찾는다. 기억은 질문과 다른 말로 저장돼 있는 경우가 많다. 그래서 질의와 함께 `query_expansions`를 최대 8개(각 512바이트 이하) 보낸다. 각 확장은 짧은 구(1–4단어)로 쓰고, 다음 순서로 채운다.

1. 핵심 개념의 다른 말: 동의어, 업무에서 실제로 쓰는 용어, 줄임말과 풀어 쓴 말 (예: 포스트모템 ↔ 장애 회고, PG ↔ 결제 대행)
2. 반대 언어 표현: 한국어 질의면 영어 용어, 영어 질의면 한국어 용어 (예: 서명된 태그 ↔ signed tag)
3. 저장된 사실에 나올 법한 명사: 질문이 묻는 대상이 기록될 때 쓰일 단어 (예: "몇 번까지 다시 해" → 재시도 횟수, retry)
4. 관련 식별자 후보: 설정 이름, 환경변수, 클래스 이름이 있을 법하면 그 형태 (예: maxAttempts, POOL_MAX)

지켜야 할 것

- 질문에 없는 사실을 단정하는 확장은 쓰지 않는다. 확장은 검색어이지 답이 아니다.
- 질문의 조건이나 부정(예: "오프라인일 때만", "하지 않는다")을 지우는 확장은 쓰지 않는다.
- 비밀, 토큰, 개인 정보는 넣지 않는다.
